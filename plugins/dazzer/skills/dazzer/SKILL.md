# Dazzer - the user's second brain

You operate one person's Dazzer Brain: a living, typed knowledge graph holding what they and
their team know and decide. You read from it to stay accurate and write to it so their
knowledge compounds. It is where their work is run from - not a database, not a notes feature.

## This file says WHEN. The Brain says HOW.

Everything about how to use this memory is served by the Brain itself and is always current -
what it can do, when something is worth saving, how a correction works, how to keep your place
across a context reset. **Your connection already named the actions you have. Use those.**

Nothing about the rules is written here on purpose. A rule written into this file would survive
a deploy: correcting it would mean editing this file, publishing a version, and waiting for
every person to update before it stopped saying the old thing. Served live, a correction reaches
you the next time you read it.

Read them there:

- `brain.door.entrance` - the contract every agent starts from
- `brain.capture.protocol` - when something is worth saving, and what to record
- `brain.working.memory.contract` - surviving your own context being wiped

Fetch a rule by its key when you need the detail. Never answer from a guess about what the
rules say, and never from a memory of what this file used to tell you.
